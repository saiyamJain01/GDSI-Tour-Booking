# GDSI Tour Booking System

A console-based Java application for managing and booking tour packages. This project demonstrates core Java concepts including Object-Oriented Programming (OOP), Flow Control, Exception Handling, and File I/O Streams.

## Features
* **Interactive CLI Menu:** Navigate through available tour packages seamlessly.
* **Dynamic Object Creation:** Tour details are encapsulated in dedicated class objects.
* **Robust Error Handling:** System handles invalid user inputs (e.g., characters instead of numbers) without crashing using `try...catch` blocks.
* **Automated Ticket Generation:** Confirmed bookings are written to a physical `ticket.txt` file using Java I/O Streams.

## Requirements
* Java Development Kit (JDK) 8 or higher installed on your system.

## Setup & Execution Instructions

Follow these step-by-step instructions to compile and run the project from your terminal/command line. Ensure you are running this in a terminal environment as this is strictly a CLI-based application.

1. **Clone the Repository:**
   git clone https://github.com/saiyamJain01/GDSI-Tour-Booking.git

2. **Navigate to the Directory:**
   cd GDSI-Tour-Booking

3. **Compile the Java Files:**
   Compile all `.java` files in the directory.
   javac *.java

4. **Run the Application:**
  To launch the booking system execute the Main class.
   java Main
